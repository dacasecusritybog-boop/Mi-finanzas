MIS FINANZAS — ARCHIVOS PARA GITHUB PAGES

Este ZIP contiene la versión web. Para publicar, extrae los archivos y sube index.html, cloud-config.js e iconos a la raíz de la rama main del repositorio. No subas este ZIP solamente: GitHub Pages no lo ejecuta.

URL del sitio: https://dacasecusritybog-boop.github.io/Mi-finanzas/

Después, en Supabase > Authentication > URL Configuration:
- Site URL: https://dacasecusritybog-boop.github.io/Mi-finanzas/
- Redirect URLs: agrega https://dacasecusritybog-boop.github.io/Mi-finanzas/**

La app usa URLs relativas para cloud-config.js. Mantén ese archivo junto a index.html.
